CyberSecurity Awareness Chatbot
Project Overview

The CyberSecurity Awareness Chatbot is a Windows Forms application developed in C# using Microsoft Visual Studio. The chatbot is designed to educate users about cybersecurity topics such as password safety, scams, phishing, and privacy while demonstrating important programming concepts including Object-Oriented Programming (OOP), collections, delegates, sentiment detection, memory management, and graphical user interface (GUI) development.

The chatbot provides an interactive and user-friendly experience where users can communicate with the system through a graphical interface.

Features
GUI developed using Windows Forms
Cybersecurity awareness tips
Keyword recognition
Random chatbot responses
Conversation flow support
Memory and recall functionality
Sentiment detection
WAV sound welcome message
Error handling for invalid input

How the Program Works
The application starts and opens the chatbot GUI.
A welcome message is displayed.
A WAV sound file plays automatically.
The user enters a message in the input box.
The chatbot analyses the message.
Cybersecurity keywords are detected.
A suitable response is generated.
The chatbot displays the response in the chat area.
User information can be stored and recalled.
Sentiment detection adjusts responses based on mood.
